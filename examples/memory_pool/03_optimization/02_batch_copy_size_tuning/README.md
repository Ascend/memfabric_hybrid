# 02_batch_copy_size_tuning

## 场景
在功能正确基础上，对主流 copy_data_batch 路径进行分块与批大小调优。

## 目标
建立可复现的 batch 吞吐/时延基线，找到当前硬件下的推荐块大小与批大小组合。

## 使用能力（仅内存池）
- `copy_data_batch`（同步）
- 基础生命周期接口（`initialize/create2/join/leave`）

## 规模建议
- world_size=2~8
- 批大小：16 / 64 / 256 / 512
- 分块：64KB / 1MB / 8MB / 16MB

## 必要条件
测试时段需尽量独占机器资源（无重负载干扰），并固定测试参数以保证结果可比。

## 验收标准
- 产出一组推荐参数（批大小+分块）
- 记录吞吐与 P95/P99 曲线
- 调优后相对默认参数有明确收益
