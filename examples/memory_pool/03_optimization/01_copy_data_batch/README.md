# 01_copy_data_batch

## 场景
作为批量拷贝数据的基础示例，演示 `copy_data_batch` 在的执行方式。

## 目标
在统一参数下完成批量拷贝并观察性能提升效果。

## 使用能力
- 基础生命周期接口
- `copy_data_batch`

## 规模建议
- world_size=1
- local_dram_size=4GB
- 总拷贝数据量：4GB
- 每个数据块大小：4MB
- 批量任务个数：32 / 128 / 256

## 必要条件
至少 1 张可用NPU。

## 验收标准
- 在 32 / 128 / 256 三组批量任务下均可稳定完成 4GB 拷贝
- 记录三组参数对应的时延与吞吐数据
