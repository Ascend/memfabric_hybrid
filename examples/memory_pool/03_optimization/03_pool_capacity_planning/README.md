# 03_pool_capacity_planning

## 场景
根据请求长度分布与并发目标，规划内存池容量并验证安全水位。

## 目标
形成容量规划方法，避免过度配置或容量不足导致风险。

## 使用能力（仅内存池）
- `create2`（`local_dram_size` + `max_dram_size`）
- 同步 `copy_data_batch` 压测
- 错误信息查询接口

## 规模建议
- 容量档：2GB / 8GB / 16GB / 32GB（按机器能力裁剪）
- 负载档：低/中/高并发三档

## 必要条件
需具备可观测的内存与时延采集手段（至少进程内存、错误码、请求时延）。

## 验收标准
- 给出容量-性能-稳定性三者折中建议
- 明确安全水位（例如目标峰值占用阈值）
- 在目标负载下无异常失败
